DataForge AI Describe the Data. We Build the Intelligence. Live

01
THE OVERVIEW

Turn any data requirement into a workflow, dataset, engine, pipeline, or output. Describe what you need in plain English — DataForge AI plans, collects, validates, and delivers a clean, source-backed dataset, with every field traceable to its source.

02
HOW THE PIPELINE WORKS

A ten-stage pipeline with observable progress at every step:

  • Understand & plan — Groq LLM parses the request into topic, location, row target, and a workflow the user can approve before anything runs.
  • Source discovery & acquisition — searches Kaggle, Hugging Face, Zenodo, Figshare, and the open web in parallel, ranks the candidates, then downloads the real rows from the selected source.
  • Clean, resolve & validate — normalizes fields, matches entities, collapses duplicates, surfaces conflicting values for review, and scores completeness and consistency.

03
KEY HIGHLIGHTS

  • Per-field provenance stored from source to final export
  • Live node-by-node progress over Server-Sent Events
  • Human review queue for conflicting values, with corrections marked verified
  • AI copilot and dataset insights grounded in actual records, not guesses
  • CSV / JSON export with a provenance manifest and role-scoped workspaces

AI Study Assistant RAG-Based Study Workspace RAG

01
THE OVERVIEW

A multi-document Retrieval-Augmented Generation application that answers questions over unstructured PDFs. Upload your course material, ask in plain English, and get context-aware answers instead of a generic chatbot response.

02
THE RETRIEVAL PIPELINE

Built with LangChain, Groq LLM, and FAISS:

  • Chunk & embed — LangChain splits documents into overlapping chunks and converts them into vector embeddings.
  • Semantic retrieval — FAISS similarity search pulls the most relevant passages for every question, across multiple uploaded documents.
  • Grounded generation — Groq LLM answers from the retrieved context, keeping responses tied to the source material.

03
STUDY FEATURES

  • Context-aware question answering over multiple PDFs
  • LLM-generated summaries, quizzes, and flashcards
  • Streamlit interface for uploads, chat, and real-time inference
  • Semantic search built on vector embeddings and similarity ranking

CollabCo Real-Time Collaborative Code Editor MERN

01
THE OVERVIEW

CollabCo is a real-time collaborative code editor where multiple people join the same room, write in the same file, and see each other's changes and cursors without refreshing the page.

02
REAL-TIME ARCHITECTURE

Built on the MERN stack with Socket.IO handling the live layer:

  • WebSocket rooms — every edit is broadcast to peers in the room and applied locally, keeping code synchronized with low latency.
  • Secure REST APIs — JWT-based authentication protects room creation, joining, and session endpoints.
  • Scalable backend — MongoDB models and optimized queries keep room state fast as concurrent editors grow.

03
KEY HIGHLIGHTS

  • Simultaneous multi-user editing with live cursor presence
  • JWT-protected rooms and authenticated socket handshakes
  • Responsive React + Tailwind CSS editor UI
  • Low-latency WebSocket synchronization over a Node.js/Express backend

04
TECH STACK

React Node.js Express.js MongoDB Socket.IO JWT REST APIs
